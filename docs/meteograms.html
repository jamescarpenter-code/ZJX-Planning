RH ≥70/80/90% shaded green, isotherms +5 to −20 °C (0 °C in blue), wind barbs colored by speed, and the red NOW line at the current time. Each chart is drawn in your browser from the newest run available when the page opens, at the model grid point nearest the airport. All six models come from Open-Meteo: GFS (NOAA), ECMWF IFS, UKMET (Met Office Global 10 km), ICON (DWD Global), GEM (Environment Canada Global) and HRRR (NOAA 3 km, 48 hours). Each chart uses the pressure levels that model provides. Arrow keys switch models; Shift + arrow keys switch airports. Link to one chart with ?site=kjax&model=hrrr.
